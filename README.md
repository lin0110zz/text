# 💖 Lovezz 音乐网页

一个以粉色系、毛玻璃和可爱贴纸为视觉风格的移动端音乐网页项目。

项目在原有音乐播放器的基础上，加入了在线搜索、多歌单、动态主角贴纸、移动端陀螺仪互动以及爱心烟花等效果。

## ✨ 当前功能

### 🎵 音乐播放器

- 5 首本地音频播放
- 唱片滑动切歌
- 播放列表管理
- 顺序播放 / 列表循环 / 单曲循环 / 随机播放
- 移动端适配
- 后台连续播放优化
- NFC 写入功能（支持的 Android 浏览器）

### 🔍 在线音乐与歌单

- 在线音乐搜索
- 搜索结果点击播放
- 将搜索结果添加到歌单
- 默认歌单「我的最爱」
- 自建歌单：新建、重命名、删除和切换
- 使用 `localStorage` 保存自建歌单

### 🖼️ 动态主角层

页面拥有两组主角贴纸：

- **主角图片**：支持陀螺仪互动，并支持随机替换
- 陀螺仪采用平滑跟随效果，并对灵敏度进行了降低，减少手机轻微晃动造成的过度位移

### 🎆 爱心烟花

主角层会实时检查当前出现的图片：

- 当同时出现 **3 张完全相同的图片**时，触发爱心烟花
- 图片可以来自随机出现，也可以来自点击替换
- 烟花采用粉色爱心粒子效果
- 烟花持续时间、大小和粒子数量经过调整，使效果更加明显
- 烟花不会改变原本的主角图片状态

### 🌸 背景效果

- 多张背景贴纸动态漂浮
- 图片随机替换
- 平滑移动效果
- 边界限制
- 移动端视觉适配

## 🎮 使用说明

### 音乐搜索

1. 打开音乐播放器页面
2. 点击播放列表区域的搜索按钮
3. 输入歌曲名或歌手
4. 点击搜索结果播放，或添加到歌单

### 歌单管理

1. 打开搜索/歌单面板
2. 进入「我的歌单」
3. 点击歌单进行切换
4. 可以新建、重命名或删除自建歌单

### 主角互动

- 在支持陀螺仪的移动设备上，允许网页访问设备方向传感器后，大组主角图片会平滑跟随手机姿态变化。
- 点击支持点击替换的主角图片，可以随机更换图片。
- 当整个主角层同时出现 3 张相同图片时，会触发粉色爱心烟花。

## ⚠️ 注意事项

1. 在线搜索和在线播放功能依赖项目中的后端接口，部署时需要同时配置对应的后端环境。
2. 自建歌单使用浏览器 `localStorage` 保存，清除网站数据后可能丢失。
3. 陀螺仪效果需要设备和浏览器支持设备方向传感器；部分浏览器可能需要用户授权。
4. NFC 网页功能取决于浏览器和设备支持情况。
5. 图片资源较多，首次打开页面时可能需要一定加载时间。

## 🔧 技术栈

- **前端**：原生 HTML / CSS / JavaScript
- **后端**：Node.js / Serverless Functions
- **存储**：`localStorage`
- **部署**：GitHub Pages + Vercel
- **设备互动**：Device Orientation API
- **动画**：原生 CSS / JavaScript
